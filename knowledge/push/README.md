# 推送业务示例知识

九个主题、十八份Markdown资料，供同组研发及相关业务方的知识查询演示。内容是原创模拟业务手册与公开官方说明的简短转述，不是公司内部原文。每份资料标记性质、对象、版本及来源，文件哈希在manifest.json中。

`acceptance.json`包含十二个预先冻结的功能验收案例，覆盖单库、多库、澄清、拒答和职责边界。它不是独立盲测集，不把通过数当通用准确率。历史IT评测资产继续保留为历史，不与新语料成绩混用。

已通过原上传接口和真实向量模型在正式站点启用，形成213个切片。原11份IT资料停用保留。12题功能样例首次终态符合预期10/12；两题分别因生成未完整结束与上游限流失败，原始结果保留，不改写为通用准确率。

实际替换、回退和验收记录见[本次交付记录](../../docs/push-knowledge-deployment-20261024.md)。生产标识、令牌、旧文件与问答正文只放Git忽略目录或服务器受限目录。
