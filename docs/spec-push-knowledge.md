# 推送知识库替换需求

用户已授权直接实施、验证及同步飞书简历和面试资料，不再分阶段请求人工确认。

## 目标与范围

把正式应用当前九个知识库从 VPN、邮箱、网络、差旅等资料替换为推送业务资料。保留现有 Python API、LangGraph、独立入库 Worker、检索和授权架构。

- 九个知识库改为推送主题，每库两份资料，共十八份；复用原知识库标识，原文件、版本、会话和账号保留。
- 新资料是公开官方说明的简短转述与原创模拟业务手册，不是任何公司的内部原文、真实事故或已实现功能承诺。
- 新资料经真实解析、切片、向量化和发布后再切换。十一份旧文档停用，不永久删除；保留切换前数据库、文件和开关清单。
- 问答默认仅检索推送资料。网页标题、登录说明与示例问题同步推送定位。
- 更新指定飞书简历、面试稿中的 RAG 业务内容、资料状态、当前问答交付方式与验证口径；保留无关项目及原有工作结构。

## 验收

1. 正式服务健康；九个库均为推送主题，十八份新文档入库完成，所有活动切片来自本次文件哈希。
2. 十一份原文档停用，旧文件与历史仍保留；普通账号无法检索旧资料。
3. 用十二个预先冻结案例验证单库、多库、拒答及缺条件行为；记录真实回答、引用、运行终态与耗时，不把功能样例当通用准确率。
4. 抽查引用原文可下载、文件哈希正确，成员用户可访问新资料；旧受限资料的授权不扩大。
5. 网页使用推送文案，原有后台执行和页面恢复接口不变。
6. 飞书修改使用当前版本保护、定点编辑和读回核对；新推送验证不能继承旧 IT 二百题成绩。

## 不包含

不接入真实推送发送、终端回执和实时经营数据，不执行生产消息发送，不添加 OCR、自治补检索或多实例授权能力，不重置用户密码。
