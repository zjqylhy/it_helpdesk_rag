3. 验证整条旧功能链的业务等价性；编排迁移本身不宣称质量提高。
4. 完成查询拆解成对实验闭环，锁定后续检索方案。
5. 独立接入并评估覆盖与条件补查，再接入并独立评估回答检查。
6. 验证全栈、数据升级与恢复；统一切换到新应用并移除旧实现，历史只留 Git 与原始报告。
