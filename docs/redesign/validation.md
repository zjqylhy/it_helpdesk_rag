完整目标流程曾尝试交互布局，复杂回边与降级分支出现通道重叠/交叉，未通过 showcase 校验。已停止该布局修复，诊断和候选保存在忽略的 `data/redesign-render/archify-target-attempt/`，不将失败 HTML 或不存在的路径作为交付。

正式交付采用完整 Mermaid/SVG 和本地图库，保留全部精确节点与条件，没有为通过布局删掉补查、修正或异常分支。当前架构交互版通过的记录与完整目标 SVG 的渲染证据分别报告，不混成同一种验证。
