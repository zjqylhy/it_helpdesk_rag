## 已实现

- `retrieval-trace-v1` 保存候选、融合、返回的重排排名/分数、选择顺序、正文字符占用、淘汰原因、重复文本 ID 及上下文哈希。保留原 Top-5 和选择行为；旧单库仅返回 Top-5，其他重排名次标为缺失。
- 只读归因区分候选、融合、重排/选择、预算/Top-K、答案组合和运行故障；锚点覆盖与人工语义裁决分开。充分性/生成失败仍保留已取到的检索证据。
- 独立 ScopeCase、审核包哈希绑定、不可覆盖的发布目录与冻结成员/授权清单。FrozenScopeStore 复用在线授权，核对主体/组、revision、成员版本、组织/default_search 和原文；检索时原文/组织漂移也会拒绝。
- baseline/split-v1 固定授权范围、模型、重排、Top-5、8000 正文字符及生成提示。拆解最多两个原问题连续片段，保留完整问题条件，不扩库；格式错误回退并记录费用。
- `scope-experiment` 按固定 seed 逐题交错执行，两组共享 HTTP 上限；续跑扣除已发请求，未执行题保持 pending，故障终态不被替换成更好答案。
- 请求发出前落盘，问答与评分计时/用量分开。孤立请求的用量、金额保留未知；价格表只用于估算，真实账单以提供商为准。
- 盲审包随机左右排列，策略映射单独保存；人工裁决后报告改善/退步/均通过/均失败。候选页可查看问题、历史、标准、原文和来源链接。
